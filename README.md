# 💰 Finance Tracker App

A modern mobile app built with **React Native** and **Expo Go** that helps users manage their **transactions** and **subscriptions**.  
The backend is powered by **Neon serverless Postgres**, with **Clerk** handling secure authentication, and deployment handled via **Render**.  

---

## 🚀 Features

- 📊 Track personal transactions in real-time  
- 🔔 Manage recurring subscriptions with reminders  
- 🔒 Secure authentication and user management with Clerk  
- ☁️ Serverless Postgres database hosted on Neon  
- 🌐 Cloud deployment with Render  
- 📱 Optimized for both iOS and Android via Expo Go  

---

## 🛠 Tech Stack

- **Frontend:** React Native (Expo Go)  
- **Backend:** Node.js / Express (API layer)  
- **Database:** Neon (Serverless Postgres)  
- **Authentication:** Clerk  
- **Deployment:** Render  

---

## 📦 Getting Started

### Prerequisites
- Node.js (>= 18)  
- Expo Go (installed on your phone or emulator)  
- Postgres database (Neon account required)  
- Clerk account for authentication  

### Installation
```bash
# Clone the repository
git clone https://github.com/your-username/finance-tracker.git
cd finance-tracker

# Install dependencies
npm install

# Run app
npx expo --start
